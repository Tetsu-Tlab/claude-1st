1-1

Claudeとは何者か（Anthropicの哲学）

Claude（クロード）は、米国 Anthropic 社が開発した対話型AIです。ChatGPTやGeminiと同じく「人の言葉で話しかけ、人の言葉で返ってくる」道具ですが、設計思想に大きな違いがあります。Anthropicは元 OpenAI の研究者たちが「もっと安全に、もっと正直に答えるAIを作る」と掲げて設立した会社で、Claudeはその看板モデルです。

具体的な性格づけとして、Anthropic は「Constitutional AI（憲法に沿って動くAI）」というアプローチを採用しています。AIに「やってはいけないこと」「守るべき価値観」を明文化したルールを与えたうえで学習させる、という発想です。結果として Claude は――

  • 勝手に走らない：指示が曖昧だと、まず確認を返す
  • 知らないことは「分からない」と言える：作話（ハルシネーション）が少なめ
  • 長文を最後まで読む：途中で要約せず、終盤の細部まで参照する
  • 倫理的に怪しい指示には慎重：個人情報を含む内容では特に

といった、「慎重でまじめな同僚」のような挙動を見せます。先生の仕事は「やり直しが利かない・人を扱う」ものが多いため、この慎重さは大きな安心材料になります。

先生にとっての立ち位置

Claudeは「優秀で、慎重で、長い文章をきちんと読んでくれる同僚」のような存在です。早口で答えるのではなく、まず文脈を読み、必要なら確認を返し、それから動く――そんなペース感のAI。所見・通知表・要録など、「ミスれない」仕事ほど Claude が向いています。

本講座で扱う Claude には、大きく分けて5つの入り口があります。それぞれ別物ではなく、1つのアカウントで全部使えると考えてOKです。

① Claude.ai（チャット版）

ブラウザで開く、いちばん基本の窓口。Projects・Artifacts などの機能はここに乗っている。STAGE 01 で習熟する基盤。

② Claude Cowork（デスクトップ）

Claude Desktop アプリの「Cowork」タブで動く、自律エージェント型の専用ツール。PC内の作業を任せられる「AI同僚」。STAGE 02 で扱います。

③ Claude Design（claude.ai/design）

ビジュアル制作専用のブラウザツール。スライド・通信・ポスターをキャンバス上で対話的に組み上げる。STAGE 02 のもう一つの主役。

④ Claude Code（CLI・IDE版）

ターミナルや Cursor のようなエディタの中に住む Claude。ファイル操作・自動化・コード生成が得意。STAGE 03 の主役。

⑤ Claude API（呼び出し版）

自作のアプリやGoogle Apps Scriptから Claude を呼び出す入り口。今回は触りだけ。Pro契約とは別料金。

⑥ Claude モバイル版

スマホアプリ。通勤中・会議の合間に「ちょっと聞く」のに便利。本講座では補助的に扱います。

1-2

Claudeの6つの強み

Claudeには他のAIにはない特徴があります。ここでは「先生の仕事に直結する」観点で6つ取り上げます。読み終わったら、ご自身の業務のどれに当てはまるか、頭の中でチェックしてみてください。

① 長文を「最後まで」読む

20万字超（小説1冊ぶん）の資料を渡しても、最後の段落の細かい言い回しまで覚えています。学習指導要領・要録の手引き・校内研究の冊子をまるごと渡せるのはClaudeの大きな武器です。

② 迷ったら「聞き返す」

指示が曖昧なとき、勝手に走らず確認してくる頻度が高い。所見・通知表など「やり直しが利かない仕事」で安心して使えます。

③ 文章とコードを両方こなす

学級通信のような文章も、GASスクリプトのようなコードも、同じ精度で扱えます。「教員の仕事は文章8割／自動化2割」の両方を1つのAIでカバーできます。

④ 安全側に寄せる設計

個人情報や倫理的にきわどい指示には慎重に答えます。児童に関する情報を扱う場面では、この保守性が逆に頼りになります。

⑤ デザイン物の生成が強い

HTML/CSS の知識をフル活用して、学級通信・ポスター・スライド・インタラクティブ教材を「作れる」AI。Artifactsでその場でプレビューできるのもClaudeの専売特許です。

⑥ 日本語が自然

「ですます調」「である調」「やわらかい語り口」「保護者向けの丁寧さ」など、日本語のレジスター（場面の使い分け）が非常に得意。所見・通信の文体調整がほぼ一発で決まります。

合言葉

「長い・難しい・間違えたくない・書類仕事」――この4つのどれかに当てはまる仕事は、まずClaudeに任せて損はありません。逆に「短いラフなアイデア出し」だけならChatGPTの方が軽快だったりします。

1-3

教職で「できること」が増える9シーン

抽象論より、具体例で見たほうが早いです。Claudeを業務に入れることで「できるようになる仕事」を9つ並べます。ここで挙げているのは「ラクになる」ではなく「これまで時間がなくて諦めていたことに手が届く」シーンです。

① 35人分の所見を、自分の文体で

観点メモを箇条書きで渡すだけで、自分の言い回しを学んだClaudeが下書きを返す。1人5分。読み返して微修正だけで仕上がります。

② 学級通信を、週1から週2へ

Artifactsで5分で下書きが出る。写真スペース・保護者欄・行事予告も型に。子どもの活躍を伝える頻度が上がる。

③ 単元計画を「全時」設計

教科書PDFと指導要領をProjectsに入れ、単元名を渡すだけ。導入→展開→まとめの全時案、中心発問、振り返り問いが揃う。

④ レベル別ワークシートを3パターン

「易・標準・発展」を一気に出力。特別支援学級や個別最適に対応した教材展開が現実的になる。

⑤ 個別の教育支援計画の更新

前年度の記録を読み込み、本年度の構成と用語を引き継いだ下書きを生成。空欄の0から書き始めなくて済む。

⑥ 校内研究の論文・冊子をいつでも質問

200ページの冊子をProjectsに入れておけば、「あの引用、どこに書いてあった？」が秒で出る。職員室の本棚が頭の中に入る。

⑦ 保護者対応の下書き

「保護者から〇〇の連絡があった。お返しのメールを丁寧に」と頼むだけ。トーン調整・誤解を生まない言い回しが得意。

⑧ 時数管理・出欠集計の自動化

Claude Code に頼めば、Google Apps Script を書いてくれる。スプレッドシートに毎日入力するだけの集計運用が完成。

⑨ 行事のスライド・ポスター

運動会・学習発表会・PTA行事のスライドや掲示物が、対話だけでHTMLで生成できる。デザインソフト不要。

大事な視点

これらは「サボる」ためではありません。Claudeに下書きを任せて空いた時間で、子どもを観察する・授業を磨く・同僚と話す・休む。教員という仕事の本丸に、時間が戻ってきます。

2-2

Claude Cowork ① ── 起動と最初のタスク

Claude Cowork は、あなたのPCの中で自律的に作業を進める「AI同僚」です。これまでのチャットは「指示を投げる→返事をもらう」が基本でしたが、Coworkは「やりたい結果を伝える → Claudeが計画を立てる → ファイル操作・ブラウザ操作・複数ステップを自分で実行 → 完了報告」までを一気通貫で進めます。Anthropicが2026年1月に発表し、2月のアップデートで Pro / Max / Team / Enterprise の全有料プランから使えるようになりました。

前提：デスクトップアプリが必須

Coworkはブラウザ版（claude.ai）では動きません。Windows / Mac 用の Claude Desktop アプリをインストールしたうえで使います。ファイル操作やブラウザ自動化を行うため、PCへの常駐が必要だからです。

起動までの5ステップ

Claude Desktop をインストール

ブラウザで claude.ai/download を開き、Windowsなら .exe、Macなら .dmg をダウンロード。指示通りにインストール。

校務PCに入れる前に、必ず情報セキュリティポリシーを確認。判断に迷うときは管理職と情報担当に相談してください。私物PCで動かすのが現実的な場合もあります。

起動して Pro プラン以上のアカウントでログイン

初回起動時に「Setting up Claude's workspace」と出てしばらく待ちます（最新版に更新する処理）。終わるとメイン画面が開きます。

画面上部の「Cowork」タブをクリック

Claude Desktopには「Chat」タブと「Cowork」タブが並んでいます。Cowork タブをクリックすると「Tasks」モードに切り替わり、左サイドバーに「Tasks」「Scheduled」「Projects」などのメニューが表示されます。

「+ New Task」で最初のタスクを作る

左上の「+ New Task」をクリックし、依頼を文章で書きます。たとえば 「ダウンロードフォルダの中の画像を、撮影日ごとにフォルダ分けして」。難しい書き方は不要、ふだん同僚に頼むのと同じ語り口でOK。

計画（Plan）を確認 → 承認 → 実行を見守る

Coworkはまず実行計画を提示してきます。「① ダウンロードフォルダを読み取る → ② 画像のメタデータから日付を取得 → ③ 日付フォルダを作成 → ④ 画像を移動」のように。承認するまで実行は始まりません。問題なければ「Approve（承認）」を押して実行スタート。途中の重要ステップでは、もう一度確認を求めてくることもあります。

来週の校外学習で撮った写真フォルダを整理して。重複は1枚残して、ピンボケは「ボツ候補」フォルダに分けて。
承知しました。以下の手順で進めます：① 対象フォルダ内の画像をスキャン（約340枚）／② 重複検出（ファイル名・サイズ・ハッシュで判定）／③ ピンボケ判定（ラプラシアン分散）／④「採用」「重複_アーカイブ」「ボツ候補」の3フォルダに振り分け。実行してよろしいですか？
OK、進めて。ボツ候補は私がもう一度目視で確認するから、削除はしないで。
了解しました。削除は行いません。実行を開始します。完了後にレポートを表示します。

Chatと決定的に違うのは、「依頼すれば、Claudeが自分で手を動かす」ところ。先生は「何を、どうしてほしいか」を伝えるだけで、ファイル操作や繰り返し作業はすべてCoworkが引き受けます。研究授業の準備、運動会の写真整理、所見メモの仕分け── 1人で抱えていた「単純作業の山」が、相談相手を得て一気に片付きます。

最初に試すべきタスク 5選

① 校外学習の写真整理（重複削除・日付フォルダ化）
② 連絡帳メモの仕分け（テキスト束を子どもごとにファイル分割）
③ 研究授業のPDF束を要約（複数PDFから論点だけ抜き出してメモ化）
④ 領収書の写真からCSV作成（出張・教材購入の表計算化）
⑤ 過去の通信12号を読んで「文体マニュアル」を作る（自分のクセを抽出）

2-3

Claude Cowork ② ── コネクター・スキル・Scheduled

Coworkが真価を発揮するのは、外部サービスや繰り返し作業とつなげたとき。ここで覚える要素は3つだけです。

C

Connectors（コネクター）

設定場所：左サイドバー → Settings → Connectors

Coworkが触れる外部サービスを有効化する場所。代表は Gmail（メール下書き／受信箱の整理）、Google Drive（ファイル参照／保存）、Google Calendar（予定参照）、Chrome（ブラウザ自動化）。
初回はOAuth認証が走り、許可した範囲だけCoworkが触れます。学校アカウントを連携する場合は、教育委員会・学校のポリシーを必ず確認。

S

Skills（スキル）

設定場所：左サイドバー → Skills

Coworkに「こういう手順で動いてね」を覚えさせるパッケージ。Anthropic公式の「PDF操作」「サブエージェント協調（複数ワークフロー並行処理）」などの組み込みスキルがあり、自分専用のスキルを書き足すこともできます（STAGE 03 で扱う Claude Code の Skill と同じ思想）。

⏱

Scheduled（スケジュール）

設定場所：左サイドバー → Scheduled

「毎週月曜の朝に、先週の連絡帳をまとめてDriveに保存」のような定期タスクを仕込む場所。Cron形式の知識は不要、「毎週月曜 7:30」のような自然な指定でOK。先生が忘れていてもCoworkが勝手に走り、結果をホーム画面に届けてくれます。

教師の業務に当てはめた4つの実例

① 月曜朝の「先週ふりかえり」自動生成

Connector：Gmail（保護者連絡）＋ Drive（学級日誌）／Schedule：毎週月曜 7:00
先週分の保護者連絡・学級日誌・出欠記録を読み、A4一枚の振り返りメモをDrive内に自動保存。職員朝会で配れる状態を、月曜の朝には作っておいてくれる。

② 行事終了後の「写真→保護者報告」一気通貫

Connector：Drive（写真フォルダ）＋ Gmail（テンプレ下書き）
行事フォルダの写真を整理してベスト10枚を選定。保護者向けの簡易報告メールの下書きまでGmailに作成して停止。送信は先生が確認してから手動で。

③ 経費精算の「写真→CSV」変換

Skill：PDF/画像 OCR（組み込み）
スマホで撮った領収書写真の束をフォルダごと渡すと、日付・金額・店名を読み取って CSV にまとめてくれる。校務支援システムへ貼り付けるだけの状態に。

④ 校内研究の「冊子→質問応答ボット」化

Skill：PDF操作 ＋ Project機能（Cowork内）
研究紀要のPDFをCoworkのProjectに登録。「あの引用、どこに書いてあった？」と聞くと、ページ番号付きで即返答。職員室の本棚を頭に入れた相棒に。

必ず守る安全運用ルール

① 個人情報を含むファイルやフォルダはCoworkに渡さない（仮名化したコピーを別途用意）
② 「削除」「上書き」「送信」など、戻せない操作は必ず確認モードで。「削除はしないで」と前置きすれば守ってくれる
③ Webから読み込ませる文書は内容を確認。第三者が仕込んだ「Claudeへの指示文」が混ざるプロンプトインジェクションのリスクがあるため
④ 校務PCで使う前に情報セキュリティポリシーを必ず確認。私物PCで生成 → 出力ファイルだけ持ち込み、という運用も現実解

Coworkは便利な分、「自分でできることの範囲」が広いツールです。Chatとは違い、勝手にファイルを動かしたりメールを下書きしたりできるので、最初の数日は「確認モード」で動かして、Coworkの動きの癖を体感してから自動化を広げていくのが安全です。

2-4

Claude Design ① ── 起動と編集UIの全体像

Claude Design は、Anthropic Labs が2026年4月にリリースしたビジュアル制作専用ツールです。Claudeの最新ビジョンモデル「Opus 4.7」が裏で動いていて、テキストの指示と素材を渡すだけで、授業スライド・学級通信・行事ポスター・ワンペーパー・インタラクティブ教材などをブラウザ内で対話的に組み上げられます。研究プレビュー段階ですが、Pro / Max / Team / Enterprise の有料プランで使えます（Enterpriseは組織管理者の有効化が必要）。

起動から初稿までの4ステップ

ブラウザで claude.ai/design にアクセス

普段の Claude.ai と同じアカウントでログイン。Coworkと違ってアプリのインストール不要。学校・自宅・出張先、どのPCからでも開けます。タブレットでも一応動きますが、編集はPCの方が圧倒的に楽。

「+ New Design」で目的を伝える

左上の「+ New Design」を押し、何を作りたいかを文章で書きます。「小学校5年・社会科『日本の工業』導入スライドを作って。10枚構成、黒板で見やすい配色」 のように。
必要なら、画像／DOCX／PPTX／XLSX をその場でアップロードできます。「Web Capture」を使えば、自治体のサイトや既存資料の画面を切り取って参照素材にすることも。

キャンバスに初稿が並ぶ

数十秒で、画面右側のキャンバスに初稿が並びます。チャットの Artifacts と違うのは、1枚ものではなく複数ページが束で並ぶこと。スライド10枚・ワンペーパー3枚・ポスター1枚── 「成果物のセット」がいきなり目の前に立ち上がります。

3つの編集UIで仕上げる

初稿を対話だけで詰めるのではなく、Designではキャンバス上で直接いじれるのが特徴。次の3つのUIを覚えれば十分です（下に詳細）。

A

インラインコメント

気になる箇所を選択して、「もう少し優しい印象に」「2行に収めて」 のように吹き出しでコメント。Claudeがその要素だけを直してくれます。授業者目線で「ここの言葉が硬い」を直接指摘できる感覚。

B

テキスト直接編集

見出しや本文をダブルクリックすると、その場で書き換え可能。「先生が手を入れたい固有名詞・学校名・日付」だけを直に修正できる。Wordのように普通に打ち直せる感覚で、Claudeを介さない作業も自然に混ぜられる。

C

調整ノブ（Knobs）

選択した要素の色・余白・フォントサイズ・角丸などを、スライダーやカラーピッカーで微調整。「全ページに適用」ボタンを押せば、変更が束ねたデザイン全体に一括反映。手で全ページ直す必要がない。

出来上がりの書き出し方

形式用途教師の代表場面
PDF配布・印刷学級通信・ポスター・配布物
PPTX（PowerPoint）編集可能なスライド研究授業の指導案配布／学校で再編集
スタンドアロンHTML電子黒板で投影授業スライド・インタラクティブ教材
Canva連携仕上げをCanvaで学校でCanva文化があるならこちら
URL共有同僚に見せる学年団に「こんなイメージ」を共有
Chat の Artifacts との違い

STAGE 01 までで触れた Artifacts は、1枚ものをChatの右側にプレビューする機能。Designは 複数ページの束を専用キャンバスで仕上げる独立ツール。「1枚の通信＝Chat の Artifacts／10枚のスライド＝Claude Design」と覚えると使い分けが効きます。研究授業のように「束で必要」なときはDesign一択。

校務PCで使うときの注意

校務PCでClaudeを使う場合、自治体・学校で利用ルールが異なります。情報セキュリティポリシーを確認のうえ、許可された範囲で利用してください。判断に迷うときは、管理職と情報担当に相談を。生成は私物PCで、出力ファイルだけ校務PCに持ち込む運用も現実解の一つです。

3-1

なぜ Cursor × Claude Code なのか

Claude Code は、ターミナル（黒い画面）やコードエディタの中で動く Claude です。「ブラウザのチャット」と違って、自分のPCのファイルを直接読んだり書いたりできるのが最大の違いです。

本講座では、Claude Code を Cursor の統合ターミナルの中で動かす スタイルを推奨します。理由は一言で言うと、「全部見える」からです。

① ファイル変更が「視覚的に」見える

Claude Code がファイルを書き換えるたびに、Cursor のエディタ画面に 差分（diff） がリアルタイム表示されます。ターミナルの文字列ではなく、色付きの差分ビューで「どこが、どう変わったか」が一瞬で分かる。怖くなくなります。

② ファイルツリーが常に見える

Cursor の左パネルに、フォルダ構成がいつも表示されます。Claude が新しいファイルを作ったり、別のフォルダを覗いたりすると、それがツリー上で点滅。「今、何が起きているか」を見失わずに済みます。

③ ターミナルとエディタが一体

下部のターミナルで Claude と対話しながら、上部のエディタで自分も編集できる。「AIに任せる部分」と「自分で書く部分」を、画面を切り替えずに往復できます。

④ Permission Mode で安全装置が効く

「計画だけ立てて、実行は手前で止まる」モードや、「編集は自動承認、実行コマンドだけ確認」モードを切り替えられます。初心者は安全側、慣れたら速度側へ。後述します。

他の選択肢との比較

VS Code でも JetBrains でも Antigravity でも Claude Code は動きます。Cursor を推す理由は「AI内蔵エディタとして設計されている」点。差分表示・選択範囲のAI連携・診断（エラー）の自動共有など、AI前提のUIが至る所にあり、Claude Code と相性が抜群です。Antigravityでアプリ開発の経験があるなら、Cursor は1日で慣れます。

3-2

インストールと初回起動

ここは「素人にもわかる雰囲気で」順を追って進めます。Windows と Mac の両方で動きます。本ガイドの想定は Windows ですが、Mac の場合は併記しています。

Cursor をダウンロードしてインストール

ブラウザで cursor.com を開き、「Download」をクリック。
Windows なら .exe インストーラ、Mac なら .dmg がダウンロードされます。指示に従ってインストール。

起動すると「VS Code の設定をインポートしますか？」と聞かれることがあります。VS Code を使っていた人は Yes、初めての人は Skip でOK。

作業用フォルダを1つ作る

デスクトップやドキュメント配下に、たとえば teacher-work という空フォルダを作ります。今後、Claude Code との作業はここに置いていきます。
Cursor を開き、「File → Open Folder」からそのフォルダを選びます。

日本語名のフォルダでも動きますが、半角英数の方がトラブルが起きにくいです。

Claude Code をインストール

Cursor の下部メニューから「Terminal」を開きます（または Ctrl + ` ※バッククォート）。
ターミナルが開いたら、下の1行を貼り付けて Enter。

【Windows / PowerShell】 irm https://claude.ai/install.ps1 | iex 【Mac / Linux】 curl -fsSL https://claude.ai/install.sh | bash 【WinGet（Windows）】 winget install Anthropic.ClaudeCode 【Homebrew（Mac）】 brew install --cask claude-code

動作確認

インストールが終わったら、ターミナルで claude --version と打ってみる。バージョン番号が出れば成功です。出ないときは claude doctor で診断できます。

Windows で「コマンドが見つからない」と出る場合は、ターミナルを一度閉じて開き直してから試す。それでもダメなら PCを再起動。

Claude Code を起動してログイン

ターミナルで claude と打って Enter。初回はブラウザが開き、Claude にログインを求められます。Pro プランに加入済みのアカウントでログインしてください。
※無料プランでは Claude Code は使えません。

ログインが終わるとターミナルに戻り、「> 」のようなプロンプトが出ます。これが Claude Code の対話画面です。

初回のあいさつをする

プロンプトに「あなたは小学校教員の補助役です。まずは自己紹介してください。」と打って Enter。Claudeが日本語で返事を返します。会話できれば準備完了です。

終了するときは /exit または Ctrl + C を2回。
ここまでで気づくこと

難しいことは何もしていません。1コマンド打って、ログインして、話しかけただけ。Claude Code はターミナルの中の「もう一人のあなた」です。これからは、その「もう一人」に仕事を頼んでいきます。

3-3

CLAUDE.md で自己紹介する

Claude Code を本格的に使い始める前に、必ずやってほしいことが1つあります。それが CLAUDE.md（クロード・ドット・エムディー）を置くことです。

CLAUDE.md は、作業フォルダの直下に置くテキストファイル。Claude Code はこのフォルダで動くとき、毎回最初にこのファイルを読みます。あなたの自己紹介・好み・ルールを書いておけば、毎回それを踏まえた応答をしてくれます。Projects の Instructions の Claude Code 版だと思ってください。

Cursor のエディタで teacher-work フォルダを開き、新規ファイル「CLAUDE.md」を作り、下のような内容を入れます。

# 私について
- 役割: 小学校5年担任（特別支援学級兼任）
- 受け持ち: 5年3組（30人）／支援学級（3人）
- 校内分掌: 学年主任・情報担当
- 興味: AI活用・授業づくり・GAS自動化

# このフォルダで頼みたいこと
- 学級通信・所見・単元計画・支援計画の下書き
- ワークシート（HTML or PDF想定の印刷物）
- Google Apps Script（時数管理・出欠集計）
- 校内研究の冊子の要約・引用検索

# 守ってほしいルール
- 文体: ですます調（保護者向けは丁寧め）
- 児童の実名は絶対に書かない（仮名はA児・B児で）
- 否定形・断定的評価は避ける
- 「がんばる」「努力する」は所見では使わない
- 不明点があれば必ず質問する（勝手に補完しない）

# よく使うファイルの場所
- 所見メモ: ./shoken-memos/
- 通信テンプレ: ./tsushin-templates/
- 単元計画: ./units/
- GAS: ./scripts/

# 連携している外部資料
- 学習指導要領（PDF）は ./docs/ 配下
- 校内研究の冊子（PDF）も ./docs/ 配下

ファイルを保存したら、ターミナルで claude を起動し直すか、現在のセッションで /init と打って再読み込みさせます。次のプロンプトから、Claude はこの自己紹介に沿って動きます。

CLAUDE.mdに書くべきこと／書かないべきこと

書くべき：毎回守ってほしいルール、フォルダ構成、用語、好み。
書かないべき：長すぎる個人史、関係のない雑談、児童の実名や住所。
コツは「もし新人の同僚が来たら最初に伝えること」を書く、です。

3-4

Permission Mode の使い分け

Claude Code は、ファイルを書き換えたりコマンドを実行したりする「力」を持っています。だからこそ、どこまで自動で動かせるかの設定が大切。Claude Code には複数の「Permission Mode」が用意されています。

Plan モード

読み取りと提案だけ。実際のファイル変更はゼロ。「何をやろうとしているか」を最後に箇条書きで提示して、人の承認を待ちます。最初の1週間はこのモード推奨。

Normal モード（標準）

1つの操作ごとに「これ実行していい？」と確認が入る。安全。慣れてくると煩わしいので、信頼できる作業はAuto-accept に切り替える流れ。

Accept Edits モード

ファイル編集は自動承認、ただしコマンド実行（Bash）は確認する。文章生成・通信レイアウトなど、ファイル操作中心の作業に最適。

Auto モード（新）

AIが安全な操作を自動判定して進める。リスクの高い行為（ファイル削除・外部送信など）は止まる。ベテラン向け。

モードの切り替えは、Claude Code のプロンプト上で Shift + Tab を押すと巡回します。画面に現在のモードが表示されます。

先生向けの推奨運用

① 最初の1週間：Plan モードで「提案だけ」見て、自分で確認しながら覚える。
② 2週目以降：Accept Edits モードで「ファイル編集は任せる」。Bashコマンドは目視確認。
③ 慣れたら：信頼できる定型作業は Auto モード、新しい作業は Plan モード、と作業内容で切り替える。
「速度より、見えていることが大事」です。

3-5

校務での実践4連発

ここからは具体例。実際に Cursor × Claude Code で何ができるかを、4つの校務で見ていきます。プロンプトは現実に使えるものを載せています。

実践①：35人ぶんの所見を一括下書き

仮名化した観点メモを児童ごとに1ファイル（./shoken-memos/A.md, B.md, ...）に保存しておきます。中身はこんな感じ。

# A児・観点メモ
- 学習面: 算数の文章題で図を使う工夫が見られる。グループ学習で説明役を担う場面が増えた。
- 生活面: 委員会活動に積極的。給食当番のとき、低学年に優しく声をかけている。
- 教師観察: 自分の意見を言葉にするのに時間がかかるが、書く力で補える。
（実名は使わず仮名A児で記述）

Claude Code にこう頼みます。

./shoken-memos/ にある全ファイルを読んで、
それぞれを CLAUDE.md のルールに沿って所見化してほしい。
出力は ./shoken-drafts/A.md, B.md ... の形で1人1ファイル。
各120字以内、3文以内、ですます調。
個人を特定する固有名詞は出さない。

Claude Code はメモを順に読み、所見の下書きをファイルとして書き出します。Cursorのエディタで shoken-drafts フォルダを開けば、出来たての下書きが並んでいます。先生は1ファイルずつ目を通して、必要なら手で修正するだけ。

実践②：学級通信を月次でまとめる

過去の通信HTMLが ./tsushin/ に12号分溜まったとします。Claude Code にこう頼みます。

./tsushin/ にある今月分の通信4号を読んで、
月次まとめページを ./tsushin/monthly-summary.html として作って。

構成:
- 各号のリード文を集約した「今月のハイライト」
- 行事カレンダー（日付付き）
- 子どもの活躍を抽出した「今月の3つのエピソード」
- 来月の予告（既存通信から拾える範囲で）

デザインは ./tsushin/template.html を踏襲。

これでHTMLが1枚生成され、保護者会や校長への提出資料として使えるレベルにまとまります。手作業で集計していたら半日コースの仕事です。

実践③：単元計画を全時ぶん設計

教科書PDFと指導要領の該当部分を ./docs/ に置いて、こう頼みます。

5年算数「割合」全12時間の単元計画を、
./docs/ にある教科書PDFと指導要領を参照して作って。

出力: ./units/wariai/
- 00-unit-overview.md（単元のねらい・評価規準）
- 01-introduction.md（第1時）
- 02-...md（以降、第12時まで）
- 99-reflection-card.md（振り返りカード3パターン）

各時の構成: めあて／導入／展開／まとめ／中心発問／板書例。
A児・B児・C児（仮名）の特性に応じた補足案を最後に1段落。

15分後にはフォルダの中に14ファイルが揃っています。ここから自分の判断で削ったり書き加えたりするだけ。0から書き始めなくて済むのが、何よりの効能です。

実践④：GASで時数管理を自動化

Google Sheets で時数管理を運用したい。Claude Code に GAS（Google Apps Script）を書いてもらいます。

毎日の授業時数を入力するGoogle Sheetsを動かすGASを書いて。

仕様:
- 日付・教科・時数・備考の4列で入力
- 別シートに「教科別累計」を自動集計
- 月末に「年間時数到達率」のシートを更新
- ウェブアプリ版として doGet で簡易フォームを表示

ファイル: ./scripts/jisu-manager.gs
コメントは日本語で。clasp で deploy する想定。

Claude Codeが書いてくれた .gs ファイルを、clasp push でGoogle Apps Script に反映。ブラウザでウェブアプリ版を開けば、毎日校務PCから入力できる時数管理ツールが完成します。Antigravity でアプリ開発経験のある方なら、ここは特に違和感なく入れるはずです。

4連発の所要時間（実測ベース）

① 所見一括下書き：15分（35人ぶん）
② 学級通信の月次まとめ：10分
③ 単元計画全12時：20分（叩き台レベル）
④ GAS時数管理：30分（ベース実装）
合計 1時間15分 で、これまで 合計30時間以上かかっていた作業 が叩き台レベルで揃います。仕上げの判断は先生の仕事として残りますが、出発点が確保される効果は計り知れません。

3-6

Skill / Slash Commands / Hooks

Claude Code をもう一段使いこなしたい人向けの3つの仕組みを、駆け足で紹介します。詳細は別講座「Antigravity Skill構築ガイド」で深掘りしますが、ここでは「何ができるか」だけ押さえてください。

Skill（自分専用のマニュアル）

.claude/skills/<名前>/SKILL.md に、特定の仕事の進め方を書いておく。Claude Code が「この種の仕事のときはこのマニュアルを見ればいい」と自動で参照してくれる。所見ジェネレーター、単元計画ジェネレーター、学級通信フォーマッターなど、繰り返す仕事はすべて Skill 化できる。

Slash Commands（呼び出しの一発化）

.claude/commands/<名前>.md にショートカット的なプロンプトを保存しておき、チャットで /<名前> と打って呼び出す。/shoken で所見モード、/tsushin で通信モード、のように切り替えられる。

Hooks（自動で動く仕掛け）

「ファイルを書き換える直前にチェック走らせる」「セッション開始時に挨拶させる」など、ルールを settings.json に書いておくと、Claude Codeが必ず実行する。「個人情報チェック」「自動バックアップ」など、強制したい安全策を入れるのに最適。

MCP（外部システム連携）

Google ドライブ、Slack、Notion、Google Calendar など、外部サービスを Claude Code から直接触れるようにする仕組み。中級者以上向け。本講座の範囲外ですが、将来的に「校務システムと連携する自分専用Bot」を作れる可能性があります。

3つを組み合わせると、たとえばこんな運用ができます。

【シナリオ：通知表シーズンの放課後ルーチン】
1. 児童ごとの観点メモを ./shoken-memos/ に書き溜める
2. ターミナルで /shoken と打つ（Slash Command が起動）
3. 内部で「所見ジェネレーターSkill」が呼ばれる
4. PreToolUse Hookが「実名チェック」を走らせる（あれば中止）
5. ./shoken-drafts/ に下書きが出力される
6. 先生はファイルを開いて目視確認・微修正のみ

「自分の働き方そのもの」を仕組みに落とせる、というのが Claude Code の本当の強さです。

3-7

学校・学年で共有する

作った Skill や CLAUDE.md は、フォルダごと配ることができます。学年団・教科部会・校内研究で展開すると、同じ仕組みを全員で使えるようになります。

  1. 共有したいフォルダを丸ごとコピー（Skill本体・参考資料・テンプレ）
  2. 受け取った先生は、自分の作業フォルダに配置（.claude/skills/ 配下など）
  3. Cursor で開き直すと、すぐに呼び出せるようになる
共有前のチェック（必ず目視で）

個人情報・校内限定情報・特定児童を想起させる記述が、SKILL.md・CLAUDE.md・テンプレファイルに残っていないか、必ず確認してから配ってください。一度配ったものは取り戻せません。 Git で管理している場合は、コミット履歴にも個人情報が残らないように要注意です。

学校全体でClaudeが浸透してくると、「あの先生のSkillをもらえばいい」「このProjectsの設計を引き継げばいい」という文化が生まれます。AIを「個人で使う道具」から「チームの仕組み」に育てていけるのが、Claude を学校に入れる本当の価値です。あなたの工夫が、学校の財産に変わります。

よくある質問

無料版でどこまでできますか？

チャットとArtifactsは無料版でも一部使えます。ただし回数制限や上位モデルの利用制限があり、Projects のフル機能や Claude Code の利用には Pro プラン（月20ドル前後）が現実的に必要です。「触ってみる」は無料、「業務で使い倒す」はPro、が目安です。Claude Code は無料プランでは使えない点に注意。

校務PCでも使えますか？

校務PCの利用ルールは自治体・学校で異なります。Claudeに限らず、生成AIの校務利用は校内規程と情報セキュリティポリシーの確認が必須です。許可された環境で、許可された情報の範囲で使ってください。判断に迷うときは、管理職と情報担当に相談を。

現実解として、「生成だけは私物PCで、出力ファイルだけ校務PCに持ち込む」というハイブリッド運用も多くの先生が採用しています。

児童の情報を入れて大丈夫ですか？

氏名・住所・連絡先などの個人情報は絶対に入れないでください。観点・行動の様子だけを仮名（A児・B児など）で扱うのが基本です。Projects の Knowledge にも、AI に送るメモにも、CLAUDE.md にも、個人を特定できる情報は残しません。

仮名化したコピーを別途用意してから Claude に渡す、というワンクッションを習慣にしてください。「入れない」が最強の防御策です。

ChatGPTを使っているのですが、乗り換えるべき？

乗り換えではなく使い分けがおすすめです。長文・所見・通知表・コードはClaude、アイデア出し・画像・GPTsはChatGPT、Workspace連携はGemini、というように役割で呼び分けるとそれぞれの強みを取り切れます。本講座ではClaudeをメインに据えていますが、他のAIを否定するものではありません。

うまく動かない／思った答えが返ってきません。

多くは指示が抽象的すぎるのが原因です。「誰向け／何字／どんな文体／避けたい表現／最終形のイメージ」を1つでも具体化すると、出力が劇的に変わります。Projects に Instructions を置く、CLAUDE.md にルールを書く、で「毎回書かなくて済む」状態を作るのが王道です。

それでもダメな場合は、プロンプトを Claude 自身に渡して「この指示の何が曖昧か教えて」と聞いてみてください。Claudeは自己診断もできます。

Claude Codeはプログラミングできないと無理ですか？

不要です。指示はほぼ日本語で、コードを書くのはClaude側です。先生は「何をやってほしいか」を言葉で伝えるだけ。最初は1ファイル・1作業からで十分です。本講座の30日プログラムは、プログラミング未経験者を想定して設計されています。

とはいえ、HTMLやCSSの初歩を眺めておくと、Designの指示精度が上がります。「display: flex で横並び」「border-radius で角丸」くらいの語彙があると指示の解像度がぐっと上がるので、興味があれば軽く触れてみてください。

なぜ Antigravity ではなく Cursor を勧めるんですか？

Antigravity（同じくAI内蔵エディタ）でも Claude Code は動きます。本講座で Cursor を推す理由は3つ。①日本語UIの完成度が高い、②差分表示・選択範囲のAI連携などClaude Code との相性が抜群、③国内外の情報量が多く詰まったとき検索しやすい。Antigravity で慣れている方はそのまま使い続けてもOKです。

料金は合計いくらかかりますか？

標準セットは「Claude Pro $20/月 ＋ Cursor 無料版 or Pro $20/月」。月 $20〜$40（約 ¥3,000〜¥6,000）が目安です。Cursor は無料版でも統合ターミナル＋Claude Codeの運用は可能なので、まずは $20/月から始めてOK。校内予算で導入できる学校も増えてきています。

30日プランをこなせる自信がありません。

大丈夫です。30日は「目安」であって「ノルマ」ではありません。1日できなくても、翌日に回せばOK。逆に、興味がある週は1日2コマ進めても構いません。大事なのは「途中でやめないこと」。 Week 2 まで進めば、Claude Code が手元に住むようになります。そこまで来れば自然と続きます。

本サイトは T-Lab 受講者向けの限定公開資料です。共有はT-Lab事務局までご相談ください。受講前にお伝えするのは構いません。

子どもたちにもClaudeを使わせていいですか？

Claudeの利用規約上、18歳未満の単独利用は制限されています。授業で子どもに触れさせる場合は、教員のアカウントで教員が操作し、子どもには出力結果のみ見せる運用が現実解です。校内ルール・保護者への説明・教育委員会との調整を経たうえで活用してください。
