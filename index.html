1-1

Claudeとは何者か（Anthropicの哲学）

Claude（クロード）は、米国 Anthropic 社が開発した対話型AIです。ChatGPTやGeminiと同じく「人の言葉で話しかけ、人の言葉で返ってくる」道具ですが、設計思想に大きな違いがあります。Anthropicは元 OpenAI の研究者たちが「もっと安全に、もっと正直に答えるAIを作る」と掲げて設立した会社で、Claudeはその看板モデルです。

具体的な性格づけとして、Anthropic は「Constitutional AI（憲法に沿って動くAI）」というアプローチを採用しています。AIに「やってはいけないこと」「守るべき価値観」を明文化したルールを与えたうえで学習させる、という発想です。結果として Claude は――

  • 勝手に走らない：指示が曖昧だと、まず確認を返す
  • 知らないことは「分からない」と言える：作話（ハルシネーション）が少なめ
  • 長文を最後まで読む：途中で要約せず、終盤の細部まで参照する
  • 倫理的に怪しい指示には慎重：個人情報を含む内容では特に

といった、「慎重でまじめな同僚」のような挙動を見せます。先生の仕事は「やり直しが利かない・人を扱う」ものが多いため、この慎重さは大きな安心材料になります。

先生にとっての立ち位置

Claudeは「優秀で、慎重で、長い文章をきちんと読んでくれる同僚」のような存在です。早口で答えるのではなく、まず文脈を読み、必要なら確認を返し、それから動く――そんなペース感のAI。所見・通知表・要録など、「ミスれない」仕事ほど Claude が向いています。

本講座で扱う Claude には、大きく分けて3つの入り口があります。それぞれ別物ではなく、1つのアカウントで全部使えると考えてOKです。

① Claude.ai（チャット版）

ブラウザで開く、いちばん基本の窓口。Projects・Artifacts などの機能はここに乗っている。STAGE 02 の主役。

② Claude Code（CLI・IDE版）

ターミナルや Cursor のようなエディタの中に住む Claude。ファイル操作・自動化・コード生成が得意。STAGE 03 の主役。

③ Claude API（呼び出し版）

自作のアプリやGoogle Apps Scriptから Claude を呼び出す入り口。今回は触りだけ。Pro契約とは別料金。

④ Claude モバイル版

スマホアプリ。通勤中・会議の合間に「ちょっと聞く」のに便利。本講座では補助的に扱います。

1-2

Claudeの6つの強み

Claudeには他のAIにはない特徴があります。ここでは「先生の仕事に直結する」観点で6つ取り上げます。読み終わったら、ご自身の業務のどれに当てはまるか、頭の中でチェックしてみてください。

① 長文を「最後まで」読む

20万字超（小説1冊ぶん）の資料を渡しても、最後の段落の細かい言い回しまで覚えています。学習指導要領・要録の手引き・校内研究の冊子をまるごと渡せるのはClaudeの大きな武器です。

② 迷ったら「聞き返す」

指示が曖昧なとき、勝手に走らず確認してくる頻度が高い。所見・通知表など「やり直しが利かない仕事」で安心して使えます。

③ 文章とコードを両方こなす

学級通信のような文章も、GASスクリプトのようなコードも、同じ精度で扱えます。「教員の仕事は文章8割／自動化2割」の両方を1つのAIでカバーできます。

④ 安全側に寄せる設計

個人情報や倫理的にきわどい指示には慎重に答えます。児童に関する情報を扱う場面では、この保守性が逆に頼りになります。

⑤ デザイン物の生成が強い

HTML/CSS の知識をフル活用して、学級通信・ポスター・スライド・インタラクティブ教材を「作れる」AI。Artifactsでその場でプレビューできるのもClaudeの専売特許です。

⑥ 日本語が自然

「ですます調」「である調」「やわらかい語り口」「保護者向けの丁寧さ」など、日本語のレジスター（場面の使い分け）が非常に得意。所見・通信の文体調整がほぼ一発で決まります。

合言葉

「長い・難しい・間違えたくない・書類仕事」――この4つのどれかに当てはまる仕事は、まずClaudeに任せて損はありません。逆に「短いラフなアイデア出し」だけならChatGPTの方が軽快だったりします。

1-3

教職で「できること」が増える9シーン

抽象論より、具体例で見たほうが早いです。Claudeを業務に入れることで「できるようになる仕事」を9つ並べます。ここで挙げているのは「ラクになる」ではなく「これまで時間がなくて諦めていたことに手が届く」シーンです。

① 35人分の所見を、自分の文体で

観点メモを箇条書きで渡すだけで、自分の言い回しを学んだClaudeが下書きを返す。1人5分。読み返して微修正だけで仕上がります。

② 学級通信を、週1から週2へ

Artifactsで5分で下書きが出る。写真スペース・保護者欄・行事予告も型に。子どもの活躍を伝える頻度が上がる。

③ 単元計画を「全時」設計

教科書PDFと指導要領をProjectsに入れ、単元名を渡すだけ。導入→展開→まとめの全時案、中心発問、振り返り問いが揃う。

④ レベル別ワークシートを3パターン

「易・標準・発展」を一気に出力。特別支援学級や個別最適に対応した教材展開が現実的になる。

⑤ 個別の教育支援計画の更新

前年度の記録を読み込み、本年度の構成と用語を引き継いだ下書きを生成。空欄の0から書き始めなくて済む。

⑥ 校内研究の論文・冊子をいつでも質問

200ページの冊子をProjectsに入れておけば、「あの引用、どこに書いてあった？」が秒で出る。職員室の本棚が頭の中に入る。

⑦ 保護者対応の下書き

「保護者から〇〇の連絡があった。お返しのメールを丁寧に」と頼むだけ。トーン調整・誤解を生まない言い回しが得意。

⑧ 時数管理・出欠集計の自動化

Claude Code に頼めば、Google Apps Script を書いてくれる。スプレッドシートに毎日入力するだけの集計運用が完成。

⑨ 行事のスライド・ポスター

運動会・学習発表会・PTA行事のスライドや掲示物が、対話だけでHTMLで生成できる。デザインソフト不要。

大事な視点

これらは「サボる」ためではありません。Claudeに下書きを任せて空いた時間で、子どもを観察する・授業を磨く・同僚と話す・休む。教員という仕事の本丸に、時間が戻ってきます。

2-1

Cowork①：Projectsで「資料を持たせる」

Projects は、Claudeに「毎回読み直してほしい資料」と「毎回守ってほしいルール」をあらかじめ預けておく機能です。チャットを開くたびに資料を貼り直す手間が消え、Claudeが「あの単元の担当」「あの学級の担任の相棒」になっていきます。

K

Knowledge（持たせる資料）

置けるもの：PDF・Word・テキスト・画像

学年の年間指導計画、学級経営案、教科書PDF、校内研究の冊子、校務分掌資料など。毎回参照したい背景情報を放り込みます。容量制限はProプランで十分すぎるレベル。

I

Instructions（守らせるルール）

置けるもの：自由記述の指示文

「ですます調で」「個人名は出さない」「3文以内で」「最後に振り返り用の問いを1つ添える」など、毎回守ってほしい型を文章で書きます。1000字程度でも問題なく機能します。

Projects を作る5ステップ

左サイドバーから「Projects」を開く

Claude.ai の左メニューに「Projects」があります。「+ New Project」をクリック。

名前と説明をつける

例：「5年算数 単元計画」「3組 学級通信」「個別の支援計画 担当児」。説明欄には「このProjectで何をするか」を1〜2文で書きます。

Knowledge にファイルを追加

教科書PDF、指導要領該当部分、年間指導計画、前年度の通信、自分の所見の見本ファイルなど。「毎回読み返してほしいもの」を厳選して入れます。多すぎると逆に精度が落ちるので、5〜10ファイル程度が目安。

児童名や個人情報を含むファイルは絶対に入れない。仮名化したコピーを別途用意してから入れる。

Instructions に「守らせるルール」を書く

文体・字数・避けたい表現・最終形のイメージなどを文章で。「ですます調・3文以内・否定形を使わない・最後に保護者への一言」のように具体的に。

新規チャットを開いて試運転

Project内で新規チャットを開き、いつもの依頼を投げてみる。応答がInstructionsに沿っているかを確認。ズレていたらInstructionsを直して再試行。最初の数回は「Instructionsの調整」が中心の作業になります。

Artifacts は、Claudeの返事のうち「成果物」と呼べる部分を、チャット画面の右側に専用の作業エリアとして開いてくれる機能です。テキスト・コード・HTML・スライド構成案など、生成物がその場でプレビュー＆編集できる「制作キャンバス」になります。

→

大事なのは、「最初から完璧を狙わない」こと。Claudeに6割の下書きを出してもらい、「ここはやわらかく」「この段落は削って」「最後に保護者への一言を足して」と、対話で少しずつ完成形に近づけます。これが Cowork（協働） の感覚です。

Coworkの極意

Claudeに丸投げするのではなく、「判断は自分、清書はClaude」と分担を決めること。先生の仕事の「何を書くか」は人にしか決められませんが、「どう書くか」はClaudeが圧倒的に速いです。先生はディレクター、Claudeは熟練のライター・デザイナー、というポジション分担。

Artifactsで出せる成果物の種類

  • テキスト：所見、通信本文、お便り、メール下書き、原稿
  • Markdown：単元計画、指導案、研究授業の構想
  • HTML：学級通信レイアウト、ポスター、スライド、インタラクティブ教材
  • SVG画像：簡単な図解・板書のイメージ・座席表
  • コード（JavaScript等）：簡易な算数ツール、フラッシュカード、計算問題ジェネレータ
  • Mermaid図：単元の構造図、人物相関図、フローチャート

1) タイトル＋号数（第○号）＋日付＋発行者

プロンプト設計の型（4要素）

STAGE 02 の最後に、すべての依頼に共通する「プロンプトの型」を渡しておきます。この型を覚えると、思い通りの出力が一発で返ってくる確率が劇的に上がります。

【役割】
あなたは〇〇の補助役です。

【入力】
- これから渡す情報：（テーマ・データ・観点）

【出力ルール】
- 文体：（ですます調 / である調 / 砕けた口調）
- 形式：（HTML / Markdown / プレーンテキスト）
- 字数：（120字以内 / 3文以内 / A4一枚）
- 避ける表現：（否定形 / 断定的な評価 / カタカナ語）

【手順】
1. 入力から事実を抜き出す
2. 観点に紐付けて整理する
3. 上のルールに従って文章化する

【最後に】
- 確認したい点があれば箇条書きで添える

4つのブロック（役割／入力／出力ルール／手順）を埋めれば、それだけでプロンプトとして十分機能します。所見も通信も単元計画も、この型から派生で書けます。

よくある失敗とその直し方

① 出力が長すぎる → 「120字以内」と字数を明記
② 同じ言い回しが多い → 「同じ語尾を3回以上連続させない」
③ 子どもの実態に合わない → 「少人数・特別支援にも対応した補足を1段落つける」
④ 学校の慣例とズレる → 避けたい語をリスト化して Instructions に追加
⑤ 急に断定的になる → 「断定を避け、可能性として書く」と明記

3-1

なぜ Cursor × Claude Code なのか

Claude Code は、ターミナル（黒い画面）やコードエディタの中で動く Claude です。「ブラウザのチャット」と違って、自分のPCのファイルを直接読んだり書いたりできるのが最大の違いです。

本講座では、Claude Code を Cursor の統合ターミナルの中で動かす スタイルを推奨します。理由は一言で言うと、「全部見える」からです。

① ファイル変更が「視覚的に」見える

Claude Code がファイルを書き換えるたびに、Cursor のエディタ画面に 差分（diff） がリアルタイム表示されます。ターミナルの文字列ではなく、色付きの差分ビューで「どこが、どう変わったか」が一瞬で分かる。怖くなくなります。

② ファイルツリーが常に見える

Cursor の左パネルに、フォルダ構成がいつも表示されます。Claude が新しいファイルを作ったり、別のフォルダを覗いたりすると、それがツリー上で点滅。「今、何が起きているか」を見失わずに済みます。

③ ターミナルとエディタが一体

下部のターミナルで Claude と対話しながら、上部のエディタで自分も編集できる。「AIに任せる部分」と「自分で書く部分」を、画面を切り替えずに往復できます。

④ Permission Mode で安全装置が効く

「計画だけ立てて、実行は手前で止まる」モードや、「編集は自動承認、実行コマンドだけ確認」モードを切り替えられます。初心者は安全側、慣れたら速度側へ。後述します。

他の選択肢との比較

VS Code でも JetBrains でも Antigravity でも Claude Code は動きます。Cursor を推す理由は「AI内蔵エディタとして設計されている」点。差分表示・選択範囲のAI連携・診断（エラー）の自動共有など、AI前提のUIが至る所にあり、Claude Code と相性が抜群です。Antigravityでアプリ開発の経験があるなら、Cursor は1日で慣れます。

場面Claude.ai（ブラウザ）Cursor × Claude Code

CLAUDE.md で自己紹介する

Claude Code を本格的に使い始める前に、必ずやってほしいことが1つあります。それが CLAUDE.md（クロード・ドット・エムディー）を置くことです。

CLAUDE.md は、作業フォルダの直下に置くテキストファイル。Claude Code はこのフォルダで動くとき、毎回最初にこのファイルを読みます。あなたの自己紹介・好み・ルールを書いておけば、毎回それを踏まえた応答をしてくれます。Projects の Instructions の Claude Code 版だと思ってください。

Cursor のエディタで teacher-work フォルダを開き、新規ファイル「CLAUDE.md」を作り、下のような内容を入れます。

# 私について

- 受け持ち: 5年3組（30人）／支援学級（3人）
- 校内分掌: 学年主任・情報担当
- 興味: AI活用・授業づくり・GAS自動化

# このフォルダで頼みたいこと
- 学級通信・所見・単元計画・支援計画の下書き
- ワークシート（HTML or PDF想定の印刷物）
- Google Apps Script（時数管理・出欠集計）
- 校内研究の冊子の要約・引用検索

# 守ってほしいルール
- 文体: ですます調（保護者向けは丁寧め）
- 児童の実名は絶対に書かない（仮名はA児・B児で）
- 否定形・断定的評価は避ける
- 「がんばる」「努力する」は所見では使わない
- 不明点があれば必ず質問する（勝手に補完しない）

# よく使うファイルの場所
- 所見メモ: ./shoken-memos/
- 通信テンプレ: ./tsushin-templates/
- 単元計画: ./units/
- GAS: ./scripts/

# 連携している外部資料
- 学習指導要領（PDF）は ./docs/ 配下
- 校内研究の冊子（PDF）も ./docs/ 配下

ファイルを保存したら、ターミナルで claude を起動し直すか、現在のセッションで /init と打って再読み込みさせます。次のプロンプトから、Claude はこの自己紹介に沿って動きます。

書くべき：毎回守ってほしいルール、フォルダ構成、用語、好み。
書かないべき：長すぎる個人史、関係のない雑談、児童の実名や住所。
コツは「もし新人の同僚が来たら最初に伝えること」を書く、です。

3-4

Permission Mode の使い分け

Claude Code は、ファイルを書き換えたりコマンドを実行したりする「力」を持っています。だからこそ、どこまで自動で動かせるかの設定が大切。Claude Code には複数の「Permission Mode」が用意されています。

Plan モード

読み取りと提案だけ。実際のファイル変更はゼロ。「何をやろうとしているか」を最後に箇条書きで提示して、人の承認を待ちます。最初の1週間はこのモード推奨。

Normal モード（標準）

1つの操作ごとに「これ実行していい？」と確認が入る。安全。慣れてくると煩わしいので、信頼できる作業はAuto-accept に切り替える流れ。

Accept Edits モード

ファイル編集は自動承認、ただしコマンド実行（Bash）は確認する。文章生成・通信レイアウトなど、ファイル操作中心の作業に最適。

Auto モード（新）

AIが安全な操作を自動判定して進める。リスクの高い行為（ファイル削除・外部送信など）は止まる。ベテラン向け。

モードの切り替えは、Claude Code のプロンプト上で Shift + Tab を押すと巡回します。画面に現在のモードが表示されます。

先生向けの推奨運用

① 最初の1週間：Plan モードで「提案だけ」見て、自分で確認しながら覚える。
② 2週目以降：Accept Edits モードで「ファイル編集は任せる」。Bashコマンドは目視確認。
③ 慣れたら：信頼できる定型作業は Auto モード、新しい作業は Plan モード、と作業内容で切り替える。
「速度より、見えていることが大事」です。

./shoken-memos/ にある全ファイルを読んで、
それぞれを CLAUDE.md のルールに沿って所見化してほしい。
出力は ./shoken-drafts/A.md, B.md ... の形で1人1ファイル。
各120字以内、3文以内、ですます調。
個人を特定する固有名詞は出さない。

Claude Code はメモを順に読み、所見の下書きをファイルとして書き出します。Cursorのエディタで shoken-drafts フォルダを開けば、出来たての下書きが並んでいます。先生は1ファイルずつ目を通して、必要なら手で修正するだけ。

実践②：学級通信を月次でまとめる

過去の通信HTMLが ./tsushin/ に12号分溜まったとします。Claude Code にこう頼みます。

./tsushin/ にある今月分の通信4号を読んで、
月次まとめページを ./tsushin/monthly-summary.html として作って。

構成:
- 各号のリード文を集約した「今月のハイライト」
- 行事カレンダー（日付付き）
- 子どもの活躍を抽出した「今月の3つのエピソード」
- 来月の予告（既存通信から拾える範囲で）

デザインは ./tsushin/template.html を踏襲。

これでHTMLが1枚生成され、保護者会や校長への提出資料として使えるレベルにまとまります。手作業で集計していたら半日コースの仕事です。

実践③：単元計画を全時ぶん設計

教科書PDFと指導要領の該当部分を ./docs/ に置いて、こう頼みます。

5年算数「割合」全12時間の単元計画を、
./docs/ にある教科書PDFと指導要領を参照して作って。

A児・B児・C児（仮名）の特性に応じた補足案を最後に1段落。

実践④：GASで時数管理を自動化

Google Sheets で時数管理を運用したい。Claude Code に GAS（Google Apps Script）を書いてもらいます。

4連発の所要時間（実測ベース）

① 所見一括下書き：15分（35人ぶん）
② 学級通信の月次まとめ：10分
③ 単元計画全12時：20分（叩き台レベル）

3-6

Skill / Slash Commands / Hooks

Claude Code をもう一段使いこなしたい人向けの3つの仕組みを、駆け足で紹介します。詳細は別講座「Antigravity Skill構築ガイド」で深掘りしますが、ここでは「何ができるか」だけ押さえてください。

Skill（自分専用のマニュアル）

.claude/skills/<名前>/SKILL.md に、特定の仕事の進め方を書いておく。Claude Code が「この種の仕事のときはこのマニュアルを見ればいい」と自動で参照してくれる。所見ジェネレーター、単元計画ジェネレーター、学級通信フォーマッターなど、繰り返す仕事はすべて Skill 化できる。

Slash Commands（呼び出しの一発化）

.claude/commands/<名前>.md にショートカット的なプロンプトを保存しておき、チャットで /<名前> と打って呼び出す。/shoken で所見モード、/tsushin で通信モード、のように切り替えられる。

Hooks（自動で動く仕掛け）

「ファイルを書き換える直前にチェック走らせる」「セッション開始時に挨拶させる」など、ルールを settings.json に書いておくと、Claude Codeが必ず実行する。「個人情報チェック」「自動バックアップ」など、強制したい安全策を入れるのに最適。

MCP（外部システム連携）

Google ドライブ、Slack、Notion、Google Calendar など、外部サービスを Claude Code から直接触れるようにする仕組み。中級者以上向け。本講座の範囲外ですが、将来的に「校務システムと連携する自分専用Bot」を作れる可能性があります。

3つを組み合わせると、たとえばこんな運用ができます。

【シナリオ：通知表シーズンの放課後ルーチン】
1. 児童ごとの観点メモを ./shoken-memos/ に書き溜める
2. ターミナルで /shoken と打つ（Slash Command が起動）
3. 内部で「所見ジェネレーターSkill」が呼ばれる
4. PreToolUse Hookが「実名チェック」を走らせる（あれば中止）
5. ./shoken-drafts/ に下書きが出力される
6. 先生はファイルを開いて目視確認・微修正のみ

「自分の働き方そのもの」を仕組みに落とせる、というのが Claude Code の本当の強さです。

3-7

学校・学年で共有する

作った Skill や CLAUDE.md は、フォルダごと配ることができます。学年団・教科部会・校内研究で展開すると、同じ仕組みを全員で使えるようになります。

  1. 共有したいフォルダを丸ごとコピー（Skill本体・参考資料・テンプレ）
  2. 受け取った先生は、自分の作業フォルダに配置（.claude/skills/ 配下など）
  3. Cursor で開き直すと、すぐに呼び出せるようになる
共有前のチェック（必ず目視で）

個人情報・校内限定情報・特定児童を想起させる記述が、SKILL.md・CLAUDE.md・テンプレファイルに残っていないか、必ず確認してから配ってください。一度配ったものは取り戻せません。 Git で管理している場合は、コミット履歴にも個人情報が残らないように要注意です。

学校全体でClaudeが浸透してくると、「あの先生のSkillをもらえばいい」「このProjectsの設計を引き継げばいい」という文化が生まれます。AIを「個人で使う道具」から「チームの仕組み」に育てていけるのが、Claude を学校に入れる本当の価値です。あなたの工夫が、学校の財産に変わります。

よくある質問

無料版でどこまでできますか？

チャットとArtifactsは無料版でも一部使えます。ただし回数制限や上位モデルの利用制限があり、Projects のフル機能や Claude Code の利用には Pro プラン（月20ドル前後）が現実的に必要です。「触ってみる」は無料、「業務で使い倒す」はPro、が目安です。Claude Code は無料プランでは使えない点に注意。

校務PCでも使えますか？

校務PCの利用ルールは自治体・学校で異なります。Claudeに限らず、生成AIの校務利用は校内規程と情報セキュリティポリシーの確認が必須です。許可された環境で、許可された情報の範囲で使ってください。判断に迷うときは、管理職と情報担当に相談を。

現実解として、「生成だけは私物PCで、出力ファイルだけ校務PCに持ち込む」というハイブリッド運用も多くの先生が採用しています。

児童の情報を入れて大丈夫ですか？

氏名・住所・連絡先などの個人情報は絶対に入れないでください。観点・行動の様子だけを仮名（A児・B児など）で扱うのが基本です。Projects の Knowledge にも、AI に送るメモにも、CLAUDE.md にも、個人を特定できる情報は残しません。

仮名化したコピーを別途用意してから Claude に渡す、というワンクッションを習慣にしてください。「入れない」が最強の防御策です。

ChatGPTを使っているのですが、乗り換えるべき？

乗り換えではなく使い分けがおすすめです。長文・所見・通知表・コードはClaude、アイデア出し・画像・GPTsはChatGPT、Workspace連携はGemini、というように役割で呼び分けるとそれぞれの強みを取り切れます。本講座ではClaudeをメインに据えていますが、他のAIを否定するものではありません。

うまく動かない／思った答えが返ってきません。

多くは指示が抽象的すぎるのが原因です。「誰向け／何字／どんな文体／避けたい表現／最終形のイメージ」を1つでも具体化すると、出力が劇的に変わります。Projects に Instructions を置く、CLAUDE.md にルールを書く、で「毎回書かなくて済む」状態を作るのが王道です。

それでもダメな場合は、プロンプトを Claude 自身に渡して「この指示の何が曖昧か教えて」と聞いてみてください。Claudeは自己診断もできます。

Claude Codeはプログラミングできないと無理ですか？

不要です。指示はほぼ日本語で、コードを書くのはClaude側です。先生は「何をやってほしいか」を言葉で伝えるだけ。最初は1ファイル・1作業からで十分です。本講座の30日プログラムは、プログラミング未経験者を想定して設計されています。

とはいえ、HTMLやCSSの初歩を眺めておくと、Designの指示精度が上がります。「display: flex で横並び」「border-radius で角丸」くらいの語彙があると指示の解像度がぐっと上がるので、興味があれば軽く触れてみてください。

なぜ Antigravity ではなく Cursor を勧めるんですか？

Antigravity（同じくAI内蔵エディタ）でも Claude Code は動きます。本講座で Cursor を推す理由は3つ。①日本語UIの完成度が高い、②差分表示・選択範囲のAI連携などClaude Code との相性が抜群、③国内外の情報量が多く詰まったとき検索しやすい。Antigravity で慣れている方はそのまま使い続けてもOKです。

料金は合計いくらかかりますか？

標準セットは「Claude Pro $20/月 ＋ Cursor 無料版 or Pro $20/月」。月 $20〜$40（約 ¥3,000〜¥6,000）が目安です。Cursor は無料版でも統合ターミナル＋Claude Codeの運用は可能なので、まずは $20/月から始めてOK。校内予算で導入できる学校も増えてきています。

30日プランをこなせる自信がありません。

大丈夫です。30日は「目安」であって「ノルマ」ではありません。1日できなくても、翌日に回せばOK。逆に、興味がある週は1日2コマ進めても構いません。大事なのは「途中でやめないこと」。 Week 2 まで進めば、Claude Code が手元に住むようになります。そこまで来れば自然と続きます。

このサイトを学校の先生にも見せていいですか？

本サイトは T-Lab 受講者向けの限定公開資料です。共有はT-Lab事務局までご相談ください。受講前にお伝えするのは構いません。

子どもたちにもClaudeを使わせていいですか？

Claudeの利用規約上、18歳未満の単独利用は制限されています。授業で子どもに触れさせる場合は、教員のアカウントで教員が操作し、子どもには出力結果のみ見せる運用が現実解です。校内ルール・保護者への説明・教育委員会との調整を経たうえで活用してください。
